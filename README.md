# SQL JOIN Practice Using MySQL

## Project Overview
This project contains practical SQL exercises designed to understand and practise different types of SQL JOINs using MySQL.

The project uses four related tables to perform queries and retrieve meaningful information from multiple tables.

## Database Information

**Database Name:** `join practice`

### Tables Used
1. `employees`
2. `departments`
3. `projects`
4. `employee_projects`

## SQL Concepts Covered

- INNER JOIN
- LEFT JOIN
- RIGHT JOIN
- FULL OUTER JOIN simulation using UNION
- SELF JOIN
- CROSS JOIN
- Multiple table JOINs
- GROUP BY with JOIN
- COUNT() with JOIN
- Finding unmatched records using NULL

## Project Tasks

The practice questions include:

- Displaying employee names with department names.
- Finding employees without matching departments.
- Identifying departments without employees.
- Connecting employees with their managers.
- Displaying every possible combination of employees and projects.
- Combining four tables using multiple JOINs.
- Calculating department-wise employee counts.

## Tools Used
- MySQL
- MySQL Workbench
- GitHub

## How to Run
1. Download or clone this repository.
2. Open the SQL script in MySQL Workbench.
3. Execute the database creation and data insertion statements.
4. Run the practice queries to explore different JOIN operations.

## Learning Objective
The objective of this project is to strengthen SQL querying skills, understand relationships between tables, and develop practical database skills useful for Data Analyst roles.
